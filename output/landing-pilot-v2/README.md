## Реальная проверка

Восемь состояний сняты в работающем сайте localhost:3000 при viewport 1440,1024,768,360. Проверена главная 644×429 и 336×224; каталог 881×320,631×269,460×240,336×189; hero 1336×573 и 336×144 CSS px. Точные дробные размеры, object-fit/object-position и соответствие файлов сохранены в measurements.json.

crop-review.webp показывает все отличающиеся пропорции. preview-*.png — отдельные изображения контейнеров. Мобильные кадры в сводке имеют натуральный размер 336 px по ширине. Телефон и светлый экран узнаваемы, заголовок и CTA образуют ясную иерархию; мелкий текст в шапке 336×144 не предназначен для чтения.

Проверка выполнена Playwright/Edge с временным перехватом ответа landing-form.webp только в отдельном проверочном браузере. Исходники сайта и public не изменены, изображения не подключены.

source-main, source-wide, source-catalog-wide — оригиналы генерации PNG и lossless WebP; полный список размеров и веса в files.json. Главная получена центральной обрезкой исходника 4:3 до 3:2, мобильный каталог — центральной обрезкой первой широкой адаптации до 16:9. Широкие оптимизированные версии сохранены в исходном размере без увеличения.
