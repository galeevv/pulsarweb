# SONORA — пробный мокап «Лендинги под рекламу»

Создан встроенным imagegen 2026-11-13. Один визуальный концепт, два согласованных кадра. Исходный код и изображения в public не изменены. Проверка выполнена на http://localhost:3000 через Playwright/Edge с локальным перехватом запроса изображения только в проверочном браузере.

## Файлы и подключение после утверждения

| Файл | Размер | Вес (КиБ) | Назначение |
|---|---|---|---|
| sonora-home-1536x1024.webp | 1536×1024 | 76.1 | Главная, desktop/tablet |
| sonora-mobile-768x512.webp | 768×512 | 19.8 | Главная mobile и каталог при ширине viewport <768 px |
| sonora-wide-1200x514.webp | 1200×514 | 43.4 | Каталог >=768 px; страница услуги на всех ширинах |
| source-master.webp | 1536×1024 | 1110.4 | Исходник основного кадра, lossless |
| source-wide.webp | 1536×1024 | 982.0 | Исходник широкой адаптации, lossless |
| source-master.png | 1536×1024 | 1776.0 | Оригинальный результат генерации |
| source-wide.png | 1536×1024 | 1627.7 | Оригинальный результат второй генерации |

Для всех файлов: object-fit: cover; object-position: 50% 50%. Размеры контейнеров менять не требуется. Основной и широкий кадры отличаются масштабом и небольшими генеративными деталями, сохраняя бренд, устройство, интерфейс и свет. Широкий файл получен обрезкой адаптированного исходника (168,265,1200,514). На максимальной ширине hero 1336 px его 1200 px слегка увеличиваются; это пробный ассет, не исходник для Retina 2x.

|---|---|---|---|
| 1440 | 644×429.33 | 881.33×320 | 1336×572.56 |
| 1024 | 456×304 | 630.66×268.80 | 960×411.42 |
| 768 | 704×469.33 | 460×240 | 704×301.70 |
| 390 | 366×244 | 366×205.88 | 366×156.84 |
| 360 | 336×224 | 336×189 | 336×144 |

Главная 3:2; каталог mobile 16:9, >=768 px динамическая ширина и высота clamp(240px,28cqw,320px), до 2.754:1; услуга 21:9. Везде cover/50% 50%. Скругление карточек 22 px; hero 32 px на tablet/desktop и 22 px mobile. Снимки отдельных контейнеров иногда округлены браузером вверх на 1 px.

Все три использования найдены в home-services.tsx, service-cards.tsx, landing-service.tsx; общий ключ landing-form в service-catalog.ts. Проект исследован в D:/Web3/pulsarweb, актуальный shadcn base-maia/Base UI, Inter, Geist Mono, нейтральная тёмная тема, primary #0071e3. Референсы просмотрены через references.webp; основной ориентир — предметный свет и материалы ноутбучных сцен, без копирования интерфейсов.

## Проверка

crop-review.webp — сводка восьми снимков реальных контейнеров с пробным изображением. preview-*.png — отдельные снимки в реальном разрешении. Мобильные кадры на сводке показаны в 1:1 CSS px. Устройство, колонка, заголовок и форма CTA различимы; мелкая навигация и вспомогательная строка на 336 px читаются плохо, композиция от них не зависит. На самой широкой карточке запас вокруг устройства небольшой, но корпус не обрезается.

measurements.json — точные замеры; files.json — размеры/байты; prompts.txt — оба использованных промпта. Снимки site-* фиксируют исходный сайт до временной браузерной подмены.
