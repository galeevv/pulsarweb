# Лендинг — ноутбук, пробник v3

Исправленное соответствие пользовательских референсов Main: landing-form.webp — ноутбук / лендинги; telegram-bloom.webp — телефон / Telegram; corporate-atelier.webp — монитор / корпоративные сайты; ecommerce-sound.webp — планшет / интернет-магазины. В этом пробнике обработан только лендинг.

Экран сохранён близко к выбранному исходнику: монолит, пейзаж, тонкие контуры, компактные элементы навигации и CTA. Акцент смещён к синему. Новая тема сайта не придумана. Использован встроенный imagegen для редактирования и широкой адаптации; полные промпты в prompts.txt. Генеративные версии не пиксельно идентичны референсу.

Также сохранены оригиналы PNG: source-main.png (1924065 байт), source-wide.png (1762800 байт). Точные размеры и вес всех ассетов в files.json.

Рекомендация для всех контейнеров: object-fit: cover; object-position: 50% 50%. Широкая версия — кадр исходной адаптации x132/y56/1652/708, без растягивания. Мобильный каталог — центральный кадр основного исходника.

Проверено в реальных контейнерах localhost:3000 через временную подмену ответа изображения только в отдельном проверочном браузере Edge/Playwright. Главная 644×429 и 336×224; каталог 881×320,631×269,460×240,336×189; hero 1336×573 и 336×144 CSS px. Точные замеры в measurements.json. crop-review.webp — все форматы, мобильные показаны при ширине 336 px без увеличения. Корпус и основной образ на экране сохраняются; мелкая навигация на мобильном не читается, в широком мобильном hero устройство заметно мельче, чем на главной.

Исходники сайта, размеры карточек и public не изменены. Подключение не выполнено. check.cjs воспроизводит проверку.
