# Почему PulsarWeb — серия 3D-иллюстраций

Установлено в D:/Web3/pulsarweb, секция #why-pulsarweb. Пять отдельных изображений созданы встроенным imagegen: прозрачный фон, сатинированный металл, матовое стекло, графит и синий акцент. Надписи в карточках сохранены; лишнего текста в изображениях нет.

| Файл в public/images/benefits | Смысл | Размер | Вес |
|---|---|---|---|
| cycle.webp | От идеи до запуска | 900×600 | 47.6 КиБ |
| contact.webp | Напрямую с разработчиком | 900×600 | 52.7 КиБ |
| solution.webp | Под вашу задачу | 900×600 | 42.6 КиБ |
| support.webp | Сопровождение включено | 900×600 | 40.5 КиБ |
| ads.webp | Готовность к рекламе | 900×600 | 54.9 КиБ |

У всех файлов сохранён реальный альфа-канал. Next Image выбирает размер изображения для устройства. object-fit: contain, object-position по умолчанию 50% 50%; внутренние отступы обеспечивают запас. Геометрия карточек и адаптивная сетка сохранены. Прежние схемы из SVG-иконок заменены в src/components/shared/why-pulsarweb.tsx; неиспользуемые импорты удалены.

## Проверка

Viewport 1440,1024,959,768,390,360: все пять изображений декодированы, pageerror отсутствуют, горизонтального переполнения страницы нет. TypeScript (tsc --noEmit) и ESLint компонента прошли. Проверены desktop и mobile визуально. На планшете широкие контейнеры не обрезают объекты благодаря contain.

preview-desktop.webp и preview-mobile.webp — чистые снимки установленной секции. Для этих снимков только в проверочном браузере скрыты закреплённый header и dev-индикатор, чтобы они не перекрывали карточки; сайт не изменён этим приёмом. qa.json содержит измерения и URL загруженных изображений.

originals/ — пять оригинальных PNG 1536×1024 с прозрачностью. prompts.json — все полные промпты, sources.json — соответствие генераций. files.json — точные размеры и байты. why-pulsarweb.before.tsx — резервная копия компонента до этой задачи. Остальные изменения пользователя в проекте не затронуты. Публикация на внешний сервер не выполнялась.
