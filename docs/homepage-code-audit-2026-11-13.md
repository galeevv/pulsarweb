# Аудит главной PulsarWeb — 13 ноября 2026

Область: главная, её компоненты, общие стили, метаданные, загрузка изображений и интеграция WebGL. Рабочая копия D:/Web3/pulsarweb. Это не полный аудит безопасности и не замер производительности на реальном телефоне.

- Удалены HomeMotion и RevealText, наблюдатели и WAAPI-анимации контента главной. Заголовки снова обычный серверный текст без дублей для анимации.

- Убраны неиспользуемые data-атрибуты анимаций и CSS. Компоненты услуг, процесса и заголовков не требуют клиентского JavaScript.
- Контент услуг центрирован по вертикали. Кнопки 48 px, на телефоне по ширине контента. Цены и пояснение Telegram хранятся в service-catalog; источник — docs/pulsarweb-landing.md, раздел 7.
- Кнопки с ценами имеют доступное имя, включающее услугу. FORM по-прежнему помечен концептом.

## Оставшиеся замечания

### P2 — контраст primary-кнопок

src/app/globals.css: белый текст на #0077FF имеет контраст 4.13:1. Проверка axe выявила color-contrast на CTA hero и кнопках цен. Для обычного мелкого текста требуется 4.5:1. Следующий шаг: немного затемнить primary-токен, сохранив белый текст; проверить также hover. Выбранный пользователем цвет в этой задаче не изменён.

### P2 — обработка отказа WebGL

src/components/shared/home-hero-surface.tsx: динамический импорт инициализирует Canvas, но локальной границы ошибок для декоративного фона нет. Нужен отдельный статический fallback и проверка при запрещённом WebGL/ошибке загрузки чанка. Поломку не воспроизводили; вывод основан на коде. Фон по прямой просьбе не менялся.

### P3 — адаптивная доставка изображений

home-services.tsx и latest-projects.tsx используют unoptimized: телефоны получают оригинальные WebP. Файлы уже сравнительно компактные: услуги 39–93 КБ, обложки проектов 88–155 КБ. Это не критический дефект. Следующий шаг: сравнить качество с next/image и корректным sizes либо подготовить отдельные размеры, не возвращая прежнее размытие. Eager для расположенных ниже hero изображений не добавлялся.

### P3 — связь высоты шапки и mobile hero

globals.css содержит margin-top: -80px для вывода фона под шапкой; 80 px соответствуют текущим 64 px высоты и 16 px внешнего отступа. Работает на проверенных размерах, но при изменении шапки значения могут разойтись. Лучше вынести геометрию в общий токен при следующем изменении layout.

## Оригинальность WebGL

Сверено с лицензированным registry prismatic-slats-tw на дату аудита, после нормализации форматирования. Шейдеры и физика эффекта совпадают. Отличия исходника: onReady после первого отрисованного кадра и frameloop demand для reducedMotion/paused вместо always. В обёртке заданы собственные синие цвета, dpr=1 вместо дефолтного 1.5 и CSS-появление после ready. Это адаптированный оригинальный компонент, не точная неизменённая копия. В этой задаче исходник и обёртка WebGL не менялись.
