## Общее направление для AI-дизайнера

Тёмный минимализм: графитовый фон, мягкий направленный свет, сдержанные металлические поверхности, один тип корпуса смартфона во всей серии. Нейтральный светлый UI PulsarVPN сохраняем: не перекрашивать кнопки в синий цвет PulsarWeb. Не добавлять неон и множество предметов вокруг устройств.

Использовать исходный скриншот как неизменяемую текстуру экрана. Не перерисовывать интерфейс, надписи, цифры, иконки и фирменные иллюстрации генерацией. Лучше сначала получить сцену с пустым экраном, затем точно вставить скриншот. Не растягивать и не обрезать важные элементы. Геометрия корпуса должна соответствовать пропорциям снимка; не обрезать UI ради рамки iPhone. При несовпадении использовать нейтральную рамку экрана.

Кабинет имеет колонку до 448 px даже на desktop. Не растягивать его в широкий dashboard. При использовании desktop-кадра можно убрать только пустые внешние поля и сохранить сам кабинет целиком.

Исходники сохранять в PNG; финальные изображения сайта — WebP, sRGB. Для обычных карточек готовить 1600×1200. Для широких кадров — 2520×1080 плюс отдельная мобильная композиция 1600×1200. Не добавлять подписи в растровую картинку: они будут HTML-текстом под ней. Сохранять редактируемый исходник композиции.

## Вертикальное видео

Экспорт 9:16, 1080×1920, MP4 H.264. Отдельный постер 1080×1920. В кадре оставить около 8–10% свободного пространства по краям для композиции и элементов управления плеером. Рекомендованная длительность 20–35 секунд.

Сценарий: авторизация → главный экран → открытие покупки → настройка параметров → подписка и устройства → рефералы / поддержка → финальный брендовый кадр. Показывать реальные состояния, не имитировать успешную оплату, которой нет в записи.

Звук необязателен; смысл понятен без него. На сайте — явное воспроизведение, pause, управление звуком, playsInline и poster; без запуска со звуком. При наличии речи добавить субтитры. Пока файла нет, на черновой странице отображается честная заглушка без неработающей кнопки Play.
