# Измерение старта главной PulsarWeb

Production build, локальный сервер 127.0.0.1:3100, Edge headless, viewport 1671×1244, DPR 1, без ограничения CPU/сети. GPU: NVIDIA GeForce RTX 4060 через ANGLE / Direct3D11. Живой сервер разработки не останавливался. Код страницы не менялся.

Три режима по 3 запуска в одном процессе браузера: исходный; WebGL отключён через тестовый getContext (тот же JS, статичный фон); WebGL и reveal-анимации отключены. Каждый запуск в новом browser context. Дополнительно первый режим повторён в новом процессе браузера.

Первый исходный запуск: ответ HTML 19 мс, первое отображение 292 мс, первая отправка отрисовки фона 5580 мс. Одна длинная задача 5377 мс; синхронный getProgramParameter после linkProgram занял 5247 мс.
Новый процесс браузера: первая отправка отрисовки фона 5365 мс, максимальная задача 5192 мс; getProgramParameter 5049 мс.
Повторные исходные загрузки в первом процессе: первая отправка отрисовки 190–192 мс, getProgramParameter около 6 мс, максимальная задача 52 мс.
Без WebGL: первое отображение 128–144 мс, максимальная длинная задача 0–55 мс. Без WebGL и reveal: первое отображение 128–132 мс, длинных задач не зафиксировано.

Вывод: воспроизведена пауза около 5 секунд на синхронном ожидании готовности WebGL-программы gradflow. Тёплые загрузки быстрые, что согласуется с кэшированием. LCP около 0.3 с в этом сценарии не отражает последующую блокировку и готовность анимированного canvas. Эти результаты относятся к тестовому Edge на данном компьютере; встроенный браузер может иметь другой GPU backend и кэш.

Варианты исправления: специализированный шейдер только для dunes; асинхронная проверка компиляции через KHR_parallel_shader_compile при поддержке; видео или статичный фон. Простая задержка запуска WebGL отложит блокировку, но сама по себе не устранит её.

Полный замер: установите PROFILE_HOME=1 и PLAYWRIGHT_CHANNEL=msedge, запустите pnpm test:e2e load-profile.spec.js. Для одного холодного повтора PROFILE_REPEAT=1. Без этих переменных профилирование пропускается в обычном наборе тестов. Сырые результаты: home-load-measurements.json и home-load-cold-repeat.json.
