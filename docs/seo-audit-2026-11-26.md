4. **Демо запрещало обход и одновременно отправляло noindex.** Полный `Disallow: /` мешал роботу увидеть noindex. Теперь HTML демо содержит `noindex, nofollow`, существующий HTTP-заголовок `X-Robots-Tag` сохранён, robots разрешает чтение публичных страниц, API закрыто для обхода. Sitemap демо пустой. Это запрет индексации, а не защита доступа к сайту.
5. **Проверки сборки захватывали архивные копии из output.** Папка исключена из TypeScript и ESLint; исходники и тесты остаются под проверкой. Архивы не изменялись.

## До индексации реального сайта

1. **Проверить production-домен и SITE_URL.** Значение по умолчанию — localhost; перед реальным запуском укажите HTTPS-origin основного домена и пересоберите сайт. Проверьте canonical, OG URL и sitemap уже через внешний адрес. Для Netlify-демо используйте адрес демо, а не будущий production-домен.
2. **Явно выбрать режим сборки.** Демо остаётся `NEXT_PUBLIC_DEMO_MODE=true`. Для индексируемого сайта установите `false` и выполните новую сборку; проверьте отсутствие noindex в HTML и заголовках, наполненный sitemap и robots. Одного изменения runtime-переменной недостаточно для статических страниц.
3. **Подключить инструменты поиска.** Подтвердите домен в Google Search Console и Яндекс Вебмастере, отправьте sitemap после публикации, проверьте выбранные поисковиками canonical и ошибки обхода. Локальный аудит не показывает позиции и фактическую индексацию.
