# Изображения для услуг PulsarWeb

Генерировать каждое изображение отдельно. Общий стиль добавлять перед каждым сюжетным промптом. Это концепты интерфейсов, не клиентские кейсы. Не копировать изображения референса.

## Общий стиль

Создай премиальный фотореалистичный editorial mockup для сайта студии цифровых продуктов PulsarWeb. Минималистичная предметная композиция, современная эстетика Apple, матовый алюминий, мягкий студийный свет, реалистичные тени. Палитра: молочно-белый, светло-серый, графит, немного тёплого песочного. В центре один главный цифровой продукт с хорошо различимым интерфейсом. Без декоративных парящих иконок, неона, водяных знаков, чужих логотипов и надписей поверх изображения. Устройства целиком в кадре, важные детали не ближе 12% к краям — изображение будет немного обрезаться и двигаться при прокрутке. Экран выглядит как качественный реальный интерфейс, а не абстрактный набор прямоугольников. Не добавляй заголовок услуги, цену или логотип PulsarWeb в изображение.

## 1. Лендинги под рекламу — site.webp

Горизонтальное изображение 3:2, 1800×1200. Открытый тонкий алюминиевый ноутбук на низком каменном подиуме. На экране стильный одностраничный сайт архитектурного проекта: большая фотография современного дома, короткий заголовок, одна заметная кнопка заявки, аккуратная навигация. Сайт с выразительной типографикой и большим количеством свободного пространства. Ракурс почти фронтальный с лёгким поворотом, экран занимает большую часть композиции. Тёплый песочный фон, мягкий дневной свет. Никаких узнаваемых чужих сайтов.

## 2. Корпоративные сайты — web.webp

Горизонтальное изображение 4:3, 1600×1200. Элегантный настольный монитор на светлом рабочем столе. На экране корпоративный сайт инженерной компании: лаконичная шапка, крупный заголовок, архитектурная фотография, ниже аккуратные блоки услуг и проектов. Светлый интерфейс с графитовыми деталями, строгая сетка. Монитор снят под небольшим углом, все грани естественные, без искажений. Светло-серый фон, мягкие объёмные тени, спокойная деловая атмосфера.

## 3. Интернет-магазины — ecommerce.webp

Горизонтальное изображение 4:3, 1600×1200. Большой тонкий планшет в альбомной ориентации на минималистичной подставке. На экране интернет-магазин дизайнерских предметов для дома: аккуратная сетка товаров с фотографиями светильников и керамики, категории, небольшая иконка корзины. Товары визуально различимы, интерфейс реалистичный и чистый. Молочно-белый фон, графитовая типографика, один небольшой песочный акцент. Один керамический предмет рядом допустим, не перегружать сцену.

## 4. Бизнес в Telegram — telegram.webp

Горизонтальное изображение 3:2, 1800×1200. Два современных смартфона на светлой матовой поверхности, один немного впереди другого. На переднем экране реалистичный Telegram Mini App для записи на услуги: карточки услуг, выбор даты и времени, заметная кнопка записи. На втором — спокойный интерфейс чата с ботом и компактное уведомление о новой заявке. Светлые интерфейсы, графитовые надписи, небольшие голубые акценты. Экран переднего телефона хорошо читается композиционно. Мягкие тени, свободное пространство, без летающих значков и огромного логотипа Telegram.

## Подключение

Сейчас используются существующие иллюстрации из public/images/services. Новые изображения сначала проверить визуально и экспортировать в WebP. Для магазина предусмотрено отдельное имя ecommerce.webp: после добавления нужно заменить поле image у ecommerce в src/config/service-catalog.ts (сейчас other). Остальные имена соответствуют текущей конфигурации. Сохранять оригиналы генерации отдельно.
